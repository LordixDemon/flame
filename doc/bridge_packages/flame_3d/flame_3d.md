# flame_3d

```{note}
`flame_3d` is an **experimental** package. It is built on Flutter GPU and
Impeller, which are experimental themselves, and its API may change at any
time without warning. Many of its modules are recent and partly untested: each
page lists what is missing under "Limitations", and the platform table in
[Getting Started](getting_started.md) tells what runs where. Try it, and expect
to work around gaps.
```
